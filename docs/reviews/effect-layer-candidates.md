# Effect layer — candidate copy for owner review

2026-10-06 · **Status: candidates only. Not implemented, not approved, not
rendered anywhere.** Batch 7 (the evidence-oriented `StudiedFor` sentences) is
also back in `owner-review`, so no plain-language copy currently reaches
customers.

The proposed ladder, top to bottom:

1. **Tags** — two or three everyday words: what the compound is about.
2. **Effect line** — one short sentence, outcome first, worded no stronger
   than the evidence.
3. The `StudiedFor` sentence (evidence-oriented, already written, held).
4. Resumen científico → the full scientific record (unchanged).

Every candidate below was written from the compound's **approved statements
only** (Batches 1–5). Statement ids are given so each line can be checked.
Nothing comes from general knowledge, even where general knowledge would say
more. In those places the row names the claim that is _not_ supported.

---

## The claim-strength grammar

The evidence class decides the verbs. The writer does not choose them.

| Class                     | When                                                                                                                           | Allowed wording (ES / EN)                                                                                                                    | Never                                                                                      |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------ |
| **A — direct outcome**    | A controlled human trial in the record reports the outcome itself (not a marker of it)                                         | Past tense, anchored to the trial and its population: _Redujo… en ensayos clínicos con…_ / _Lowered… in clinical trials in…_                 | Present-tense general claims ("reduce el peso") — that turns a trial result into a promise |
| **B — qualified outcome** | Human evidence that is a biomarker, a single small or uncertain trial, an association, or a modest effect stated with its size | _Se ha asociado con… · Elevó [marcador]… · En un ensayo…_ / _Has been associated with… · Raised [marker]… · In one trial…_                   | Turning a marker into a benefit (GH ↑ ≠ more muscle)                                       |
| **C — research topic**    | Preclinical, mechanistic, observational, related-compound, or human studies whose results the record does not state            | _Se investiga por… · Se estudia en relación con… · En [animal] se observó…_ / _Researched for… · Studied in relation to… · In [animals] it…_ | Any wording that reads as an effect in people                                              |
| **D — no simple effect**  | Classification only, a combination with no study, or a compound for which any simple effect line would mislead                 | **No tags, no effect line.** The `StudiedFor` sentence alone.                                                                                | Manufacturing one                                                                          |

**Tags** (controlled vocabulary, ES / EN). A tag names a _topic_ the approved
statements cover. It never carries strength: the effect line beside it does.

## Decisions this needs from you before any wording

1. **Class A is a legal question as much as a scientific one.** Every A line
   states a weight or blood-sugar outcome for a compound that is a
   prescription medicine elsewhere and is sold here for research use. The
   wording is sourced and trial-anchored, but whether NEOGEN may state an
   efficacy outcome on a product page at all is for regulatory review.
   CLAUDE.md lists "weight-loss … efficacy claims" among what must not be
   invented. These are not invented, but they are efficacy claims.
2. **Tags on preclinical compounds.** "PESO" beside AOD9604 is accurate as a
   topic, but a shopper may read it as an effect. Options: (a) tags for every
   class A–C, as drafted below; (b) tags only for A and B; (c) tags for C only
   when the effect line names the animal model. I recommend (c), which is how
   the candidates are drafted.
3. **Dermorphin** (an opioid, studied in rat overdose research) and
   **Melanotan 2** (unlicensed; the only clinical source is an adverse-event
   case report): both drafted as D. Whether they belong in the catalogue at all
   is outside this pass. It is flagged so the question is not lost.

## What happens after review

When you mark lines approved, changed or rejected, the layer would be built the
same way as `StudiedFor`. Each tag and each effect line would be pinned to its
statement ids, with the class stored and the verb list per class enforced by
`check:content`. It would sit in its own review batch, so it can be withdrawn
without touching anything else. No UI work happens before that.
